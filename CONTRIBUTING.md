# 贡献指南 / Contributing

欢迎通过 Issue 和 Pull Request 改进流畅度、交互、美术、无障碍与机型兼容。
Issues and pull requests improving performance, interaction, artwork, accessibility, and device compatibility are welcome.

- 提交问题请包含应用版本、手机型号、系统版本、复现步骤及预期行为。
  Include app version, device model, Android version, reproduction steps, and expected behavior.
- 截图和日志先移除个人信息及表演内部设置。
  Remove personal information and internal performance settings from screenshots and logs.
- 保持修改集中，说明验证方式；逻辑修改运行相关测试，交互修改进行设备验证。
  Keep changes focused, explain validation, run relevant tests, and check interaction changes on a device.
- 新素材需说明来源并附许可。
  Attribute new assets and include their licenses.
- 公开标题、说明及演示不讲解具体魔术原理。
  Keep explanations of the performance method out of public titles, descriptions, and demos.

构建方法 / Build instructions: [Development](docs/DEVELOPMENT.md)。
