# 安卓魔术软件 berglas

**一张木桌，一副纸牌，一场属于你的表演。**

[English](README.en.md) · [开发说明](docs/DEVELOPMENT.md) · [贡献指南](CONTRIBUTING.md)

berglas 是一款面向安卓手机的离线纸牌魔术表演工具，使用 Kotlin 与 Jetpack Compose 开发。经典红蓝扑克牌、木质桌面与自然的拖动和翻牌交互，共同构成简洁、沉浸的表演空间。

本项目独立开发，与同名人物、品牌或机构无关联。

## 表演效果：ACAAN

berglas 面向 Berglas / **ACAAN（Any Card At Any Number，任意牌任意数字）** 风格的纸牌魔术表演。

观众自由说出一张扑克牌，比如 **红桃 7**，再自由说一个 **1～52** 的数字，比如 **23**。魔术师随后拿出一副牌，一张一张数到第 23 张，结果那张牌正好就是红桃 7。

这个效果最核心的观感就是：

**牌是观众选的，数字也是观众选的，但那张牌偏偏就在那个位置。**

以上描述的是经典效果与本项目的表演方向。当前版本提供可交互的纸牌表演工具，需要配合表演者的流程使用；尚未提供输入任意数字后自动数牌的功能。公开说明不讲解具体实现原理。

## 功能亮点

- 纯本地运行，无需账号、服务器，应用不申请网络权限。
- 52 张独立牌，可逐张拖动、自由摆放，移动时自动置顶。
- 单指双击翻牌，单击不会翻开；正反面的牌均可移动。
- 红蓝两套牌背，配合分层牌盒、纸边和柔和阴影。
- 牌盒向下退出，前后保持同一木纹桌面。
- 状态与界面分层，包含单元测试及设备测试，方便持续开发。

## 下载与安装

在本仓库的 **Releases** 页面下载发布者提供的 APK，传到 Android 手机后打开安装。最低支持 **Android 8.0（API 26）**。标记为 debug 的安装包用于测试体验。

如果尚未发布安装包，可按[开发说明](docs/DEVELOPMENT.md)自行构建。首次构建需联网下载开发依赖，安装后的应用可离线使用。

## 基本体验

1. 打开应用进入牌桌，从牌盒中央区域向下滑动取出牌堆。
2. 按住可触及的纸牌拖动，松手后停留在当前位置。
3. 用同一根手指连续点击同一张牌两次进行翻牌。
4. 双击桌面空白处展开纸牌，也可找回移出屏幕的牌。
